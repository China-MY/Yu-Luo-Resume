## 专科毕业设计

### 📋 项目概述
**项目名称**：基于SpringBoot的智慧校园管理系统  
**完成时间**：2024年  
**项目角色**：项目负责人、全栈开发工程师

### 🎯 项目背景
针对传统校园管理系统功能单一、用户体验差等问题，设计并开发了一套集成化的智慧校园管理系统，旨在提升校园管理效率和师生使用体验。

### 💡 核心功能
- **用户管理模块**：支持学生、教师、管理员多角色权限管理
- **课程管理模块**：课程信息维护、选课管理、成绩录入等功能
- **通知公告模块**：校园新闻发布、通知推送、消息管理
- **数据统计模块**：学生成绩分析、课程统计、用户行为分析

### 🛠️ 技术实现
- **后端技术**：SpringBoot + MyBatis + MySQL
- **前端技术**：Vue.js + Element UI + Axios
- **开发工具**：IntelliJ IDEA + Git + Maven
- **部署环境**：Linux + Nginx + Tomcat
